## What this package follows

`nwlsm` fits latent space models for network ties (Hoff, Raftery and Handcock 2002). The reference implementation is the R package latentnet
(Krivitsky and Handcock; GPL). The code of nwlsm is written independently from the published method; no code of latentnet is included.
